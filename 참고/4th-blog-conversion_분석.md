# 블로그 유닛(4th-blog-conversion)에서 가져올 것

> 출처: 스폰지클럽 4기 블로그 수익화 유닛 저장소 `selfishclub/4th-blog-conversion` (유닛장 키노·케이), 1·2주차 요약과 2주차 세션자료. 2026-11-03 정리.

## 1. 제휴 고지 — 표현 기준 (G7 보충)

- 「AD」, 「Sponsor」, 「파트너스」만 쓰는 건 고지로 인정되지 않는다. **무엇을 받는지 한국어로** 쓴다 (예: 「수수료 지급」, 「판매수익의 일부 지급」).
- 숨기지 않는다: 「더보기」 안, 본문 중간, 댓글, 작은 글씨 ✕
- 근거: 공정위 「추천·보증 등에 관한 표시·광고 심사지침」, 경제적 이해관계 표시 안내서(2025.12 개정) — 세션자료 기준, 원문은 `확인 필요`
- (선택) 고지를 글자 대신 **캡처 이미지**로 넣으면 AI 인용을 덜 방해한다는 팁. 이미지로 넣어도 맨 위·눈에 띄게.

## 2. 네이버 에디터에서 쓰는 법

- 에디터 **체류 시간이 길수록 사람이 쓴 글로 본다** → 붙여 넣고 바로 나오지 말고, 에디터에서 직접 손보고 예약하기
- 에디터를 **모바일 화면 모드**로 바꿔서 쓰기 · 줄바꿈은 짧게
- 줄글 대신: **인용구 · 구분선 · 스티커 · 굵은 글씨 · 짧은 문단 · 사진** 적극 사용
  - 지금 자동 넣기는 `---` 를 빈 줄로만 넣는다 → 리아가 검수할 때 구분선·인용구로 바꾸기

## 3. 검색·AI 인용에 잘 걸리는 글

- 블로그는 **검색해서 문제를 해결하러 오는 곳** → 일기보다 정보 중심 구조
- AI 브리핑 인용을 노린다면: **소제목 · 비교표 · 반복 키워드 · 전문 지식(근거)**
- 케이 사례: 오래된 아이디로 리빙 블로그를 새로 열고 20일 만에 「백김치 담그는 방법」이 네이버 AI 브리핑 첫 결과로 노출. 전략은 「수제 버거가 아니라 **맥도날드**」 — 표준화된 글쓰기
- **내 다른 글 링크**를 본문에 넣으면 방문자당 페이지뷰가 는다 (사례: 방문자 180명 → 조회수 240회)
  - 키트엔 시리즈 다음 글 연결만 있음 → 시리즈가 아니어도 관련 글(예: 센터포인트 ↔ 쉐라톤, 공항 픽업 ↔ 두짓타니 파타야) 서로 연결

## 4. 어필리에이트 플랫폼 메모

| 플랫폼 | 메모 |
|---|---|
| 쿠팡 파트너스 | 수수료는 높지만 네이버가 외부 링크를 싫어해 **누락이 잦음** |
| 쇼핑 커넥트 | 네이버 자체 어필리에이트, 최근 오픈 |
| 세시간전 | 여행 중심 → 도서·G마켓 등으로 확장 중. **크롬 확장 프로그램**으로 보고 있는 페이지에서 바로 제휴 링크 생성 (트립닷컴 검색 결과 페이지 → 하이퍼링크, 교보문고 도서 → 카드 형태) |

- 세시간전 조건(세션자료, 출처: 세시간전 블로그 2024.12 기준 — 가입·출금 전 다시 확인): 수수료 최대 10% 안팎, **정산 익월 25일, 최소 출금 5만 원**
- 내 블로그와 **핏이 맞는 카테고리**로 고르기 (여행 블로그 → 호텔·여행사·항공)
- 상품은 **내 경험과 이어지는 것**부터 → 광고처럼 안 읽힘

## 7. 블로그 세팅 체크리스트 (「수줍은 여행자 빵배쏙」 점검용)

- [ ] 블로그 아이디: 특수기호·하이픈 없이 단순한 단어 (변경 기회 1번뿐)
- [ ] 블로그명: 정체성·전문 분야가 바로 보이게
- [ ] 별명: 영문 아이디 말고 하는 일과 연관된 한글 키워드
- [ ] 스킨: 수평선·베이지 계열 심플한 디자인
- [ ] 기본 서체: 나눔스퀘어·고딕 같은 각진 서체 (손글씨체 ✕)
- [ ] 글씨 크기: 15~19pt
- [ ] 카테고리: 4개 안팎 · 앨범형(정방형) · 페이지당 글 1개
- [ ] 퍼스널콘 설정
- [ ] 오래된 아이디가 있으면 새로 만들지 말고 살리기 · 예전 글은 지우지 말고 비공개 + 별도 카테고리
