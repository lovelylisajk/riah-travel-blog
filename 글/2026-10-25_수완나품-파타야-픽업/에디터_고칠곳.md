# 네이버 에디터에서 고칠 곳 (G9 대조 결과, 2026-10-25)

> 원고 기준. 리아가 에디터에서 직접 고친다. 다 고치면 이 파일은 지워도 된다.

## ① 한 줄 빠짐 — 「▶ 공항 → 파타야 버스」 끝부분

「(출처: RRC 공식 홈페이지 시간표, … KB국민은행 같은 날 기준)」 바로 아래에 이렇게 되어야 해요.

```
버스는 터미널에 내려 주니까        ← 이 줄이 빠짐
거기서 숙소까지 또 가야 해요.
캐리어 2개 끌고 한 번 더 움직이는 거죠.
```

## ② 줄 자리 바뀜 — 「▶ 새벽 비행기면요?」

사진(새벽 샌딩 차량) 아래가 이렇게 되어야 해요.

```
그런데 공식 시간표를 보면
파타야에서 공항 가는 버스 첫차는   ← 여기 있어야 함
· 좀티엔 터미널 출발 06:00
· 파타야 북부터미널 출발 08:00
이에요.
```

지금은 이 줄이 「▶ 택시는요? (자료 조사)」 소제목 **앞에 붙어서**
「파타야에서 공항 가는 버스 첫차는▶ 택시는요? (자료 조사)」 한 줄이 되어 있어요.
→ 앞부분을 잘라 위 자리로 옮기고, 소제목은 「▶ 택시는요? (자료 조사)」만 남기기.

## ③ 줄 자리 바뀜 — 「▶ 저는 픽업 차량을 탔어요」 끝 ※ 안내

```
※ 연착 때 기다려 준 건 제가 이용한 곳 이야기예요.
상품마다 대기 규정이 다를 수 있으니   ← 여기 있어야 함
예약 전에 꼭 확인해 주세요.
```

지금은 이 줄이 **글 맨 끝**(마지막 ※ 안내 다음)에 가 있어요. → 맨 끝 줄은 지우고 위 자리에 넣기.

## ④ 글자 사라짐 — 「▶ 지금 예약할 수 있는 픽업·샌딩 상품」 ① 상품 아래

```
👉 왜 여기냐면요     ← 지금은 「👉」만 있음
```

## 그 밖에 확인할 것
- 제휴 링크 3곳: `[제휴 링크: 마이리얼트립 3441167]` 등 → 파트너센터에서 만든 링크로 바꾸기
- 🔒 사진 가리기 (사진 클릭 → 편집 → 모자이크/스티커)
  - 1번째 사진(공항 입국 통로): 사람 얼굴
  - 2번째(새벽 샌딩 차량), 5번째(차와 캐리어), 7번째(호텔 도착): 차량 번호판
  - 4번째(차량 사진 메시지): 휴대폰 속 번호판·대화 상대 이름
- 리아가 바꾼 문장(예: 「안녕하세요, 여행수줍입니다.」)은 원고.md와 달라져요.
  다 고친 뒤 알려 주면 에디터 내용을 원고.md에 맞춰 반영하고, 그 문장도 다시 검사(G2·G8·G10)할게요.
