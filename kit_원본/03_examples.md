# 실제 사례 — 통과한 것 / 막힌 것

> 전부 제 블로그에서 실제로 있었던 일입니다. 숫자는 제휴 스튜디오·네이버 통계 실측입니다.

## ✅ 통과해서 돈이 된 글

### 충주 활옥동굴 — 입장권 글에 숙소를 붙였더니
- 글감: 폭염에 아이 데리고 갈 실내 장소
- 건 링크: 입장권 1 + **근처 숙소 3**
- 결과: 입장권 링크 **48클릭 → 0건** / 켄싱턴리조트 **11클릭 → 전환 36.4%**
- 7/31 숙소 결제 발생 → **22,509원**
- 배운 것: **입장권은 사람을 데려오는 미끼**다. 데려온 사람에게 팔 것을 반드시 같이 걸어야 한다.

### 괌 PIC vs 두짓타니 — 조건을 못 박은 비교
- 뼈대의 "비교 기준" 칸: `같은 대한항공 4박5일 · 성인 1인 · 9/8~9 출발`
- 본문 핵심: 두짓타니 1,066,030원 / PIC 1,133,930원 → **67,900원 차이인데 PIC는 점심·저녁 포함**
- 배운 것: 값만 나열하면 비교가 아니라 착시다. **조건을 못 박은 순간 독자가 판단할 수 있게 된다.**

## 🚫 관문에 막힌 것 (막혀서 다행이었던 것)

### G2에 막힘 — 8,300원짜리 유령 상품
- 검색 결과 요약에 남아 있던 워터파크 입장권 8,300원을 본문에 쓸 뻔함
- 실제로 눌러보니 **이미 판매 종료된 상품**
- 만약 나갔으면: 독자가 링크를 눌렀는데 상품이 없다 → 그 글의 신뢰가 통째로 깨짐

### G1에 막힘 — 어디서도 안 파는 펜션
- 별그림 펜션을 정하고 가격·시설·후기까지 다 조사함
- 그 뒤에 확인해보니 여기어때에도, 야놀자에도 없음 (전화 예약만)
- 조사 통째로 버림 → **그래서 G1을 조사 "전"으로 옮겼다**

### G8에 막힘 — 조용히 사라진 본문
- 발행 프로그램이 "삽입 완료 · 임시저장 완료"를 찍음
- 실제 화면: **도입부 없음 · 소제목 3개 없음 · 이미지 4장 없음**
- 눈으로 열어보고서야 발견. 이후 붙여넣기 뒤 화면 대조를 강제

## 📉 실패에서 나온 숫자

| 믿었던 것 | 실제로 재보니 |
|---|---|
| 싼 게 잘 팔린다 | 입장권·쿠폰 9건 = 10,563원 / 숙소 4건 = **112,134원** |
| 클릭 많은 글이 돈이 된다 | 클릭 1위 글(100클릭) = **0원** |
| 쿠키가 긴 판매처가 낫다 | 쿠키 30일 판매처 건당 1,509원 / 쿠키 7일 판매처 건당 **28,863원** |
| 검색량 큰 키워드를 노려야 한다 | 큰 키워드는 대형 블로그가 선점 → **내 체급 세부 검색어**가 실제로 뜸 |

## 🔁 4주차 — 검사에 걸린 것을 AI가 고치고 다시 검사한 사례

**글**: 어느 도시의 11·12월 날씨 정보글 (실제 실행 기록)

| 단계 | 무엇을 했나 | 걸린 것 | 본문 길이 | 모델 호출 |
|---|---|---|---|---|
| ① 원본 | AI가 초안을 씀 | **6건** — 내부 메모 노출 1 · 분량 미달 1 · 줄머리 기호 4 | 1,410자 | 1회 |
| ② 다시 쓰기 | AI가 *"이 6건은 내가 고쳐도 되는 종류다"* 라고 판정하고 그 6건만 고침 | **1건** — 연결어미 뒤 쉼표 (고치다 **새로 생김**) | 2,258자 | +1회 |
| ③ 규칙 교정 | 모델 없이 정해진 규칙으로 쉼표 4군데를 뺌 | **0건** → 사람 검수 대기 | 2,254자 | **+0회** |

**여기서 배운 것**

- **AI가 고치면서 없던 문제를 만듭니다.** ②에서 6건을 다 고쳤지만 쉼표 하나를 새로 넣었습니다.
- 그래서 ③은 **모델을 또 부르지 않았습니다.** 한 번 더 부르면 또 다른 걸 만들 수 있어서, 답이 하나뿐인 형식 문제는 규칙으로 끝냈습니다.
- 「AI가 잘 고쳤다」가 아니라 **「AI가 만든 부스러기를 규칙이 쓸었다」** 가 맞는 말입니다.

## 🔁 4주차 — 고칠 게 없는 글은 한 글자도 안 건드린 사례

같은 장치를 켜고 글 한 편을 새로 썼더니:

```
AI 원본 응답  5,507바이트   →   교정본  5,507바이트   (완전히 동일)
교정 0건 · 걸린 것 0건
```

**이건 「AI가 스스로 좋아진 사례」가 아닙니다.** 고칠 게 아예 없었던 것뿐입니다.
그래도 적어두는 이유는, **손댈 이유가 없을 때 손을 안 대는 것**도 확인이 필요하기 때문입니다.
원본을 따로 보관하고 교정본을 검사에 넣기 때문에, 둘을 나란히 놓고 **뭐가 바뀌었는지 항상 대볼 수 있습니다.**

## 🚧 4주차 — 규칙 학습이 안전 검사에 막힌 사례

AI가 *"이 사람은 이렇게 고치더라"* 규칙안 **10개**를 냈는데, 안전 검사에 걸려 **하나도 안 들어갔습니다.**

걸린 이유 세 가지:

| 규칙안에 섞여 있던 것 | 왜 막았나 |
|---|---|
| *"겪은 일화·혼잣말은 새로 넣되"* | **없는 경험을 지어내라**는 뜻 |
| *"메타문장은 통째로 지우고"*, *"근거가 있어도 남기지 않고"* | **근거를 지우라**는 뜻 |
| *"스펙 표 자체를 통째로 빼기도 하며"* | **표를 통째로 지우라**는 뜻 |

**막힌 건 고장이 아닙니다.** 그냥 들어갔으면 없는 경험을 지어내는 글이 나갔을 겁니다.
다만 **10개 중 하나만 위험해도 10개가 다 버려지는 것**이 지금의 한계입니다. `05_loop.md` 아래쪽에 같은 이야기가 있습니다.
