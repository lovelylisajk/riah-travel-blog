# 안 가본 곳도 파는 블로그 — Starter Kit

> 경험이 없는 분야로 어필리에이트 글을 쓸 때, **틀린 정보가 새어나가지 않게** 막아주는 최소 세트.
> 제 여행 블로그 기준으로 만들었지만, 상품·지역 이름만 바꾸면 다른 분야에도 그대로 씁니다.

## 이게 뭔가요

AI에게 "속초 숙소 글 써줘" 하면 글은 나옵니다. 문제는 **그 안의 가격이 작년 것**이고, 소개한 숙소가 이미 안 파는 곳이라는 겁니다.
저는 여행을 안 다니는 사람이라 **틀려도 제 눈에 안 걸립니다.** 그래서 사람 대신 기계가 검사하게 만들었습니다.

이 키트는 그중 **혼자서도 30분이면 세팅되는 부분**만 뽑은 것입니다.

| 파일 | 무엇 |
|---|---|
| `00_instructions.txt` | AI에게 주는 지침 — 글 쓰기 전에 반드시 거치는 순서 |
| `01_factsheet.md` | 재료 장부 — 값마다 **어디서 봤는지**를 같이 적는 양식 |
| `02_gate.md` | 검사 관문 8개 — 통과 못 하면 발행을 멈춘다 |
| `03_examples.md` | 통과한 글 / 막힌 글 실제 사례 |
| `04_fix_rules.md` | 🆕 **모델을 안 불러도 고쳐지는 것** — 정해진 규칙으로 교정 |
| `05_loop.md` | 🆕 **한 바퀴 도는 순서** — 문제를 AI가 확인하고 고친 뒤 다시 검사 |
| `06_dashboard.md` | 🆕 **상태 확인 표** — 잘 돌고 있는지 한 화면에서 (빈 서식 + 루프 사례 표) |

## 4주차에 뭐가 늘었나

3주차 키트는 **틀린 글이 안 나가게 막는 것**까지였습니다. 막고 나면 거기서 끝이라 **사람이 고쳐야** 했습니다.
이번에 그 뒤를 붙였습니다.

```text
[3주차]  글을 쓴다 ──▶ 검사한다 ──▶ 걸리면 멈춘다 ──▶ 사람이 고친다

[4주차]  글을 쓴다 ──▶ 검사한다 ──▶ AI가 걸린 것을 스스로 나눈다
                                        │
                         ┌──────────────┼──────────────┐
                         ▼              ▼              ▼
                   규칙으로 끝     다시 써야 함      사람만
                   (모델 0회)      (모델 1회)      (여기서 멈춤)
                         └──────────────┴──▶ 다시 검사 ──▶ 사람 승인
                                                              │
                                        상태 확인 표 ◀────────┘
```

**실제로 이렇게 줄었습니다** — 글 한 편에서 검사 걸린 것 **6건 → 1건(AI가 고침) → 0건(규칙으로 고침)**.
그리고 **다음 글로 넘기는 한 바퀴**도 실제로 돌려봤습니다 — AI가 개선안 한 개를 스스로 내고,
다음 원고 프로그램이 **그 파일을 직접 읽었습니다**(`05_loop.md` 아래쪽).
자세한 건 `03_examples.md` 맨 아래에 있습니다.

## 처음 만들 때 요령

- **팩트시트가 8할입니다.** 값마다 `출처`와 `조회일`을 적게 만드세요. 이게 없으면 AI가 옛 가격을 그대로 씁니다.
- **관문은 처음부터 다 만들지 마세요.** 저도 0개에서 시작했습니다. 틀릴 때마다 하나씩 붙이는 게 맞습니다.
- **"없다"와 "모른다"를 구분**하게 하세요. 두 곳만 보고 "안 판다"고 썼다가 실제로는 팔고 있던 적이 있습니다.
- 관문은 **글을 다 쓴 뒤가 아니라 쓰기 전에** 걸리는 게 몇 개 있어야 합니다. 다 쓴 뒤엔 구조를 못 고칩니다.

| 있으면 좋음 | 표를 붙일 노션이나 구글 시트 |

## 이 키트로 안 되는 것

- 실제 발행(네이버 에디터 자동 입력)은 브라우저 자동화가 필요해서 뺐습니다 — 그건 도구 설치가 따로 필요합니다.
- 성과 측정·문체 학습 같은 밤 자동화도 뺐습니다. 먼저 **틀린 글이 안 나가는 것**부터가 순서입니다.

- **상태 확인 표를 기록에서 자동으로 채워주는 스크립트는 안 들어갔습니다.** 제 폴더 구조에 묶여 있어서, 여기엔 **표 서식과 채우는 법**만 넣었습니다. 손으로 채워도 며칠이면 흐름이 보입니다.
- **사실이 맞는지 보는 관문은 여전히 없습니다.** 출처 주소가 적혀 있는지까지만 봅니다. 그 값이 정말 그 출처와 같은지는 **사람이 열어봐야** 합니다.
