# 04. 모델을 안 불러도 고쳐지는 것 — 정해진 규칙으로 교정

> 검사에 걸린 것 중 **절반쯤은 AI를 다시 부를 필요가 없는 형식 문제**입니다.
> 그런 건 정해둔 규칙으로 끝내고, AI는 정말 다시 써야 하는 데만 씁니다.

## 왜 나누나

AI에게 "이것도 고쳐줘"라고 다시 시키면 두 가지가 따라옵니다.

- **돈과 시간이 또 듭니다.**
- **고치다가 없던 문제를 만듭니다.** 실제로 겪었습니다 — 목록 기호 4건을 고쳐달라고 했더니 다 고쳐놓고 문장에 쉼표 하나를 새로 넣었습니다.

형식 문제는 답이 하나뿐입니다. 판단이 필요 없으면 **AI를 부를 이유도 없습니다.**

## 갈라 담는 법

검사에 걸린 항목을 두 통에 나눠 담습니다. **한 항목은 한 통에만** 들어갑니다.

| 통 | 어떤 것 | 누가 고치나 |
|---|---|---|
| **A. 규칙으로 끝** | 답이 하나뿐인 형식 문제 | 정해진 규칙 (모델 0회) |
| **B. 다시 써야 함** | 내용을 새로 만들어야 하는 것 | AI에게 다시 시킴 (모델 1회) |
| **C. 사람** | 사실이 맞는지, 팔아도 되는지 | 사람 |

**C가 하나라도 섞여 있으면 A도 B도 돌리지 않습니다.** 사람이 먼저 봐야 합니다.

### 내 분야에 맞게 채우세요

| | 우리 것 |
|---|---|
| **A에 넣을 것** (답이 하나뿐인 형식) | `[ 예: 줄머리 기호 · 특정 연결어미 뒤 쉼표 · 금지된 기호 ]` |
| **B에 넣을 것** (다시 써야 하는 것) | `[ 예: 분량 모자람 · 내부 메모가 샘 · 빠진 항목 ]` |
| **C에 넣을 것** (사람만) | `[ 예: 값이 출처와 다름 · 파는 곳이 바뀜 · 법적 표시 ]` |

## A통 규칙 — 이렇게 좁게 적으세요

⚠️ **여기가 제일 위험한 자리입니다.** 규칙을 넓게 잡으면 멀쩡한 글을 망칩니다.

제 검사기는 *"한글 뒤에 `고`·`며`·`지만` 이 붙고 쉼표가 오면 걸림"* 이라고 **잡습니다.**
그런데 이걸 그대로 **고치는 데** 쓰면 안 됩니다.

```
망고, 사과, 딸기를 넣습니다      ← '망고,' 가 걸립니다. 여기 쉼표는 지우면 안 됩니다
사고, 화재, 도난에 대비합니다     ← '사고,' 도 마찬가지
홍대, 합정, 상수를 돕니다         ← '홍대,' 도 마찬가지
```

**잡는 규칙과 고치는 규칙은 달라야 합니다.** 잡을 땐 넓게, 고칠 땐 **적어놓은 것만.**

### 고쳐도 되는 말 목록 (여기에만 손댑니다)

```
하지만,   되지만,   있지만,   없지만,   높지만,   낮지만,
있고,     없고,     있으며,   없으며,
확인하고,  준비하고,  살펴보고,
함께 보고,      ← '보고,' 만 있으면 안 됩니다. 「보고서」일 수 있어서요
```

`[ 여기에 내 분야에서 자주 나오는 형태를 더 적으세요. 확실한 것만. ]`

### 손대지 않는 곳

- 글 맨 위 정보 칸 · 제목 · 인용문 · 표 · 코드 · HTML
- 주소(URL)와 링크 안쪽
- 큰따옴표 안 (남의 말을 옮긴 것)
- **애매하면 그 줄은 통째로 건너뜁니다**

### 줄머리 기호 바꾸기

```
- 이것        →     · 이것
* 이것        →     · 이것
+ 이것        →     · 이것

1. 이것       →     그대로 둡니다 (번호는 뜻이 있을 수 있어서)
  - 이것      →     그대로 둡니다 (안으로 들여쓴 것)
- [ ] 이것    →     그대로 둡니다 (체크 상자)
```

`[ 내 플랫폼이 삼키는 기호가 다르면 여기를 바꾸세요 ]`

## 예시 — 넣은 것과 나온 것

**넣은 글 (가상)**

```markdown
---
제목: 예시 글
---

# 예시 글

가격은 [공식 안내](https://example.com/price)에서 확인할 수 있지만, 날짜마다 다릅니다.
조식은 있고, 주차는 없고, 수영장은 있으며, 체크인은 15시입니다.
망고, 사과, 딸기가 조식에 나옵니다.
준비물은 함께 보고, 예약은 따로 합니다.

- 여권 유효기간
- 우기 여부
1. 첫째 날
  - 안으로 들여쓴 줄
```

**나온 글**

```markdown
---
제목: 예시 글
---

# 예시 글

가격은 [공식 안내](https://example.com/price)에서 확인할 수 있지만 날짜마다 다릅니다.
조식은 있고 주차는 없고 수영장은 있으며 체크인은 15시입니다.
망고, 사과, 딸기가 조식에 나옵니다.
준비물은 함께 보고 예약은 따로 합니다.

· 여권 유효기간
· 우기 여부
1. 첫째 날
  - 안으로 들여쓴 줄
```

**뭐가 바뀌었나 — 7군데**

| 줄 | 바뀐 것 | 왜 |
|---|---|---|
| 본문 1행 | `있지만,` → `있지만` | 목록에 있는 말 · **주소는 그대로** |
| 본문 2행 | `있고,` `없고,` `있으며,` → 쉼표 뺌 | 목록에 있는 말 (한 줄에서 3군데) |
| 본문 3행 | **안 바뀜** | `망고,` 는 목록에 없는 말 — 나열 쉼표를 지키는 자리 |
| 본문 4행 | `함께 보고,` → `함께 보고` | 완전한 구 그대로일 때만 |
| 목록 | `- ` → `· ` (2줄) | 플랫폼이 삼키는 기호 |
| 번호 목록 | **안 바뀜** | 번호는 뜻이 있을 수 있어서 |
| 들여쓴 줄 | **안 바뀜** | 안으로 들여쓴 것은 안 건드림 |
| 맨 위 정보 칸·제목 | **안 바뀜** | 손대지 않는 곳 |

## 지켜야 할 것

1. **원본은 지우지 않습니다.** 모델이 준 원본을 따로 저장하고, 교정본을 검사에 넣습니다. 둘을 나란히 놓고 뭐가 바뀌었는지 항상 볼 수 있어야 합니다.
2. **바꾼 자리를 전부 기록합니다.** 몇 줄, 무슨 규칙, 바꾸기 전/후.
3. **교정 뒤에 숫자·주소·제목이 그대로인지 다시 셉니다.** 하나라도 달라졌으면 **교정본을 버리고 원본을 씁니다.**
4. **교정하다 실패하면 「실패」로 남깁니다.** 통과로 바꾸지 않습니다.
5. **같은 글에 두 번 돌려도 결과가 같아야 합니다.** 달라지면 규칙이 잘못된 것입니다.
