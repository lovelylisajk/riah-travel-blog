여기 담은 건 깔아야 할 것 · 가입해야 할 것 · 받아서 뭘 하면 되는지, 딱 첫 글 한 편까지예요. 밤마다 도는 자동 수집·측정·문체 학습 같은 건 나중 이야기라 뺐어요.

이 킷으로 할 수 있는 것. 도구를 깔고 아래 마스터 프롬프트를 붙여넣으면, Claude가 키워드 고르기부터 초안·문체 다듬기·네이버 에디터에 붙여넣기까지 이끌어 줘요. 서버는 필요 없고, 노트북 한 대면 돼요.

이 킷이 아닌 것. 제 블로그를 통째로 복제하는 게 아니에요. 검사 22관문·자동 발행기·키워드 저울 같은 전체 엔진은 담지 않았어요. 여기 든 건 도구 지도와 시작 프롬프트까지예요.

1세팅 순서

위에서 아래로 그대로 따라가면 돼요. 각 단계에 걸리기 쉬운 지점 하나씩 적어 뒀어요.

  1. Anthropic 가입 + Claude 구독

    claude.ai에서 가입하고 구독해요. 이게 전부의 열쇠예요.

    걸리는 곳: 구독이면 돼요. 종량 과금 API 키를 따로 발급받을 필요 없어요.

  2. Claude Code 깔기

    claude.ai/code의 공식 안내대로 설치해요. 터미널에서 claude라고 치면 켜져요.

    걸리는 곳: 터미널이 처음이라도 괜찮아요. 뜨면 한국말로 바로 시키면 돼요.

  3. Orca + Tailscale 깔기 (폰에서 밖에서도 쓰고 싶을 때)

    집 맥과 폰, 두 기기에 Tailscale을 같은 계정으로 로그인해요. 그다음 Orca를 깔면 폰에서 집 맥의 작업을 보고 시킬 수 있어요.

    걸리는 곳: 두 기기 같은 계정 로그인이 핵심. 집에서만 쓸 거면 이 단계는 건너뛰어도 돼요.

  4. AI 브라우저 깔고 네이버 로그인

    맥: ego lite를 받아요. 깔면 ego-browser 스킬이 같이 들어와요. ego 안에서 네이버에 로그인해 두면, AI가 그 상태로 발행해요.

    윈도우: Aside를 받아 네이버에 로그인해요. 그다음 Claude Code에 연결해요. 순서대로 PowerShell에서:

    1. Aside 개발자 안내의 윈도우 설치 명령으로 aside 명령어를 깔아요.
    2. aside login --email "내 이메일" → Aside 앱의 설정 › 계정 › 기기에서 코드 승인. "Signed in as..."가 뜰 때까지 기다려요.
    3. claude mcp add aside -- aside mcp → Claude Code를 다시 켜면 Aside를 쓸 수 있어요.

    걸리는 곳: 사람 창과 AI 창이 따로 떠요. AI가 일하는 창을 사람이 만지면 AI가 멈추고 물어봐요. 윈도우에서 aside를 못 찾으면 터미널을 새로 열어요.

  5. 스킬 붙이기

    글 품질용 humanize-korean과 작업 방식용 superpowers를 넣어요. 보통은 저장소를 받아 ~/.claude/skills에 연결하거나, 플러그인은 /plugin marketplace add로 설치해요. (방법은 각 저장소 안내에 있어요.)

    걸리는 곳: 스킬은 ~/.claude/skills에 두면 어디서든, 프로젝트 폴더 안에 두면 그 프로젝트에서만 떠요.

✓첫 글 올려보기

도구를 다 깔고 아래 마스터 프롬프트로 시작하면, 실제 흐름은 이래요. (네이버 붙여넣기는 맥이면 ego lite, 윈도우면 Aside에 네이버 로그인이 필요해요.)

  1. 폴더를 열고 Claude Code를 켜요

    글을 쓸 작업 폴더에서 claude를 켜고, 아래 마스터 프롬프트를 붙여넣어요.

  2. 주제를 말하면 초안이 나와요

    쓰고 싶은 주제를 말하면 Claude가 자료를 모아 초안을 써요. humanize 스킬로 문체도 다듬어요.

  3. 네이버에 붙여넣어요

    Claude가 AI 브라우저(ego lite 또는 Aside)로 네이버 에디터를 열어 원고를 붙여넣어요. 여러분이 먼저 읽고 고친 뒤 발행하면 돼요.

▶복붙해서 시작하는 마스터 프롬프트

설치가 끝났으면, Claude Code를 켜고 이 프롬프트를 그대로 붙여넣으세요. 내 도구·환경이 뭔지 알려주고, 블로그 자동화를 어떻게 굴릴지 전체 그림을 같이 세우는 프롬프트예요.

시작 프롬프트
너는 내 블로그 자동화를 돕는 파트너야. 한국어로 진행하고, 나는 개발자가 아니야.

[목표]
네이버 블로그에 어필리에이트(제휴) 글을 꾸준히 쓰는 작업을 Claude Code로 자동화하고 싶어.
키워드 고르기 → 자료 수집 → 초안 → 문체 다듬기 → 네이버에 올리기 → 성과 보기까지의
흐름을 만들고 싶어.

[내 환경과 도구]
- Claude Code : 지금 너를 쓰는 곳. 터미널에서 한국말로 시킨다.
- Orca + Tailscale : 집 밖(폰)에서도 집 컴퓨터의 작업을 보고 시킨다.
- ego lite(맥) 또는 Aside(윈도우) : 네이버·제휴 사이트를 다루는 AI용 브라우저. 네이버 글쓰기 창을 열고 붙여넣는 건 여기로 한다.
- humanize-korean (스킬) : 글의 'AI 티'를 빼고 문체를 다듬는다.
- superpowers (스킬) : 일을 계획하고 단계로 나눠 진행하는 방식.
- 세시간전(3hoursahead) : 여행 제휴 링크 발급·성과 확인.
- 네이버 검색광고 API : 키워드의 월 검색량·경쟁도를 가져와 '언제 뭘 쓸지' 판단.

[부탁]
1. 먼저 내 상황을 물어봐 줘. 무엇을 이미 깔았는지, 어떤 주제의 블로그인지, 하루에 얼마나 시간을 쓸 수 있는지.
2. 그다음 위 도구들을 어떤 순서로, 어디에 쓰면 좋을지 전체 그림을 그려 줘. 지금 당장 할 수 있는 것과 나중에 붙일 것을 나눠 줘.
3. 매번 글을 쓸 때 따르는 '작업 흐름'을 나와 함께 정하고, 짧은 체크리스트로 남겨 줘.
4. 원칙: 사실은 확인하고, 안 본 걸 본 척하지 말고, 과장하지 마. 발행 버튼은 내가 직접 누른다.
   - 브라우저 작업은 맥이면 ego lite의 `ego-browser` 명령어로, 윈도우면 Aside MCP 도구로 한다. 다른 브라우저 도구를 새로 깔지 마.
   - API 키·비밀번호는 채팅에 쓰지 말고 `.env` 파일에 넣게 안내해 줘.
   - 우리가 정한 작업 흐름과 규칙은 이 폴더의 `CLAUDE.md`에 저장해서 다음에도 이어 가.
   - 첫 주는 자동화보다 글 한 편을 끝까지 올려 보는 데 집중한다.
   - 제휴 링크가 들어간 글엔 "링크를 통해 구매 시 수수료를 받습니다" 문구를 넣는다.

이 중에서 지금 첫걸음으로 무엇부터 하면 좋을지 하나만 골라 제안하면서 시작해 줘.
