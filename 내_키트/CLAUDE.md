# 리아의 방콕 여행 블로그 — 작업 흐름

> 스폰지클럽 케이의 「블로그 자동화 스타터킷」에서 시작해 리아(이재경)에 맞게 바꾼 버전.
> 원본은 `../kit_원본/` (읽기 전용, 고치지 않는다).

## 나는 누구고 무엇을 쓰나

- 글쓴이: 리아. 본업은 베이킹 공방 운영. 개발자가 아니니 쉬운 말로, 전문용어는 괄호로 풀어 준다.
- 블로그: 이미 있는 네이버 블로그. 주 3~5시간 쓸 수 있다.
- **v1 글 종류 (고정)**: 방콕 숙소 소개 1~3곳 + 「공항·역에서 숙소까지 가는 법」 섹션
- 독자: **방콕에 처음 가는 자유여행자.** 공항에서 숙소까지 가는 게 제일 걱정인 사람.
- 말투: **수다스러운 블로그체** (「저는 여기서 진짜 헤맸거든요 ㅠㅠ」). 단, 수다·감상은 **직접 묵은 곳에만**.
- v1 밖의 글감(치앙마이, 파타야, 가족여행 호텔, 빵집·카페)은 하지 않고 `../WORKLOG.md` 「다음에」로 보낸다.

## 꼭 지키는 원칙

1. **본 척하지 않는다.** 숙소마다 `직접 묵음` / `자료 조사` 를 정하고 글에도 밝힌다.
   `자료 조사` 숙소에는 「묵어 보니」「가 보니」「제가 써 보니」 같은 체험 문장을 쓰지 않는다.
2. **값 하나에 출처 하나.** 가격·시간·요금·운행 정보는 팩트시트에 출처와 조회일이 있어야 본문에 쓴다.
   모르면 지어내지 않고 `확인 필요`로 남긴다. 검색 요약·AI 답변에서 본 값은 쓰지 않는다.
3. **과장하지 않는다.** 「무조건」「최고」「놓치면 후회」 같은 가짜 긴급성 금지.
4. **돈 표기**: 바트 먼저, 원화는 `약 ○○원 (환율 YYYY-MM-DD 기준)`. 숙소 가격은 날짜·인원·세금 포함 여부까지.
5. **제휴 고지**: 링크가 하나라도 있으면 글 맨 위 고지 + 링크 바로 옆 `(제휴)` 표시. 문구는 `02_검사관문.md` G7.
6. **사진은 리아가 찍은 것만.** 남의 사진·글을 그대로 가져오지 않는다. 사진 자리는 `[사진: 무엇]` 으로 비워 둔다.
7. **발행 버튼은 리아가 누른다.** 제휴 가입·로그인·결제도 리아가 직접 한다. AI는 에디터에 붙여 넣기까지만.
8. **비밀은 `.env` 에만.** 비밀번호·API 키를 채팅이나 파일에 쓰지 않는다.
9. **0원 유지.** 유료 API·유료 서비스는 쓰지 않는다. 선택 항목(네이버 검색광고 API 등)은 넣기 전에 리아에게 묻는다.
   케이 님 페이지의 추천인 링크는 리아 블로그에 넣지 않는다.
10. **키트 파일은 스폰지클럽 밖으로 내보내지 않는다.** (공개 저장소·블로그·단톡방 금지)

## 글마다 쓰는 체크리스트 (짧은 버전)

- [ ] 숙소마다 `직접 묵음` / `자료 조사` 표시가 있다
- [ ] 모든 숫자에 출처 + 조회일이 팩트시트에 있다. 모르는 건 `확인 필요`
- [ ] 바트 먼저, 원화는 환율 기준일과 함께
- [ ] 가는 법: 요금·소요 시간·운행 시간(첫차·막차)에 출처가 있다
- [ ] 같은 종류 링크 3개 이하, 「저라면 여기」 1곳
- [ ] 맨 위 고지 + 링크 옆 `(제휴)`. 쿠팡 링크가 있으면 쿠팡 지정 문구
- [ ] 사진 자리는 리아 사진으로만
- [ ] 네이버 화면에 소제목·문단·표가 다 들어갔다

## 이 컴퓨터 메모 (Windows)

- `python3` 는 윈도우 스토어 가짜 실행 파일이라 안 돈다. **스크립트는 `python` 으로 실행한다.**
  humanize-korean 스킬이 `python3 ...` 을 부르면 `python ...` 으로 바꿔 실행한다.
- 브라우저 작업은 **Aside MCP 도구**로만 한다 (`../.mcp.json`). 다른 브라우저 도구를 새로 깔지 않는다.
  네이버 로그인은 Aside 브라우저 안에서 리아가 직접 해 둔다.
- Claude Code는 데스크톱 앱으로 쓴다. 터미널용 `claude` 명령은 없다.
