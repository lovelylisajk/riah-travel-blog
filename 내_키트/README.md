# 리아의 방콕 여행 블로그 키트

방콕 숙소 소개 + 「공항에서 숙소까지 가는 법」 글을 **Claude와 함께 한 편씩** 쓰고,
틀린 정보가 새지 않게 검사한 뒤, 네이버 에디터에 붙여 넣기까지 가는 내 작업 세트예요.
발행 버튼은 내가 직접 눌러요.

## 들어 있는 것

| 파일 | 무엇 |
|---|---|
| `CLAUDE.md` | Claude가 매번 따르는 작업 흐름 · 원칙 · 체크리스트 |
| `01_팩트시트.md` | 글마다 복사해서 채우는 재료 장부. 값마다 출처와 조회일 |
| `02_검사관문.md` | 발행 전 관문 9개 (원본 8개 중 필요한 것 + 새로 2개) |
| `04_고침규칙.md` | 검사에 걸린 걸 규칙 / Claude / 나 세 통으로 나눠 고치는 법 |

원본의 `03`(사례) · `05`(반복 순서) · `06`(상태 표)은 v1에선 뺐어요. 글이 쌓이면 내 사례로 다시 만들어요.

## 어떻게 쓰나

1. Claude Code 데스크톱 앱에서 `리아-여행블로그` 폴더를 열어요. (Aside 앱도 켜 두고, 네이버에 로그인돼 있어야 해요)
2. 이렇게 말해요:
   > 방콕 숙소 글 하나 쓰자. 숙소는 ○○(직접 묵음), △△(자료 조사), 출발은 수완나품 공항.
3. Claude가 판매처 확인 → 팩트시트 → 뼈대 4칸(여기서 한 번 보여 줌) → 초안 → AI 티 빼기 → 검사 순서로 가요.
4. 원고를 읽고 고친 뒤 「붙여 넣어 줘」라고 하면, Aside로 네이버 글쓰기 창에 넣고 화면을 대조해요.
5. 사진을 넣고 **발행은 내가** 눌러요.

## 필요한 것

- Aside (윈도우용 AI 브라우저) + aside 명령어 — 폴더의 `.mcp.json` 으로 연결돼 있어요

- 네이버 계정 (Aside 안에서 로그인)

## 이용 조건

이 폴더의 키트 파일(원본과 수정본)은 스폰지클럽 안에서만 쓰는 학습용이에요.
공개 저장소 · 블로그 · 단톡방에 올리거나 강의 · 상품으로 쓰지 않아요.
이 키트로 만든 내 워크플로우는 내 블로그에 써도 되고, 소개할 땐 출처를 남겨요.
